## 1. Lesson Overview

**Unit:** Unit 1 | **Lesson:** Lesson 3 | **Topic:** Writing numbers in standard, expanded, word and short-word forms

**Lesson title:** Many Forms to Write Numbers

**Main mathematical topic:** The different ways of writing the same whole number — standard form, expanded form, word form and short-word form — for numbers up to milliards.

**What students learn in Lesson 3:**

* Standard form: the number written in digits with commas showing the periods.
* Expanded form: the number written as the sum of the values of its digits.
* Word form: the number written in words, with commas separating the Millions, Thousands and Ones periods.
* Short-word form: digits combined with period names, such as 778 million, 340 thousand, 821.
* That zeros are not written in expanded form, because there is nothing in that place value.
* How to convert between any two of these forms.

**Main mathematical concepts:** standard form, expanded form, word form, short-word form, place value of each digit, role of zero.

**Important skills developed:** writing numbers in standard, word and expanded forms; converting from words or expanded form to standard form; reading and writing large numbers accurately with commas.

#### Notes from the source

* Numbers written in expanded form show the value of each digit.
* Note for parents: a place value with a 0 digit is not represented in expanded form. For example, 30,456 = 30,000 + 400 + 50 + 6; the 0 is not represented because in standard form the 0 shows that there is nothing in that place value.

### Definitions

**Definition — Standard form**

Standard form is the way of writing a number using digits, with commas used to show the periods, for example 778,340,821.

**Definition — Expanded form**

Expanded form is writing a number as the sum of the values of its digits, for example 778,340,821 = 700,000,000 + 70,000,000 + 8,000,000 + 300,000 + 40,000 + 800 + 20 + 1.

**Definition — Word form**

Word form is writing a number completely in words, using commas to separate the Millions, Thousands and Ones periods, for example "Seven hundred seventy-eight million, three hundred forty thousand, eight hundred twenty-one".

**Definition — Short-word form**

Short-word form is writing the digits of each period followed by the name of the period, for example 778 million, 340 thousand, 821.

### Rules

**Rule — Zeros in expanded form**

Zeros are not written in expanded form, because a zero digit means there is nothing in that place value.

**Rule — Commas in standard form and word form**

In standard form, commas separate the periods of three digits. In word form, commas separate the Milliards, Millions, Thousands and Ones periods.

**Rule — Three digits per period**

When changing word form or short-word form into standard form, each period must contain exactly three digits (except possibly the leftmost period), and empty places are filled with zeros.

### Procedures / Methods

**Method: Word form (or short-word form) → standard form**

1. Identify the periods named in the words: milliard, million, thousand, ones.
2. Write the number of each named period.
3. Fill any missing period or missing place with zeros so each period after the first has exactly three digits.
4. Insert commas between the periods.

**Method: Standard form → expanded form**

1. Name the place of each digit.
2. Write the value of each digit (digit followed by the zeros of its place).
3. Join the values with plus signs, skipping any digit that is 0.

**Method: Expanded form → standard form**

1. Look at the largest value in the sum to know how many places the number has.
2. Write each digit in the place shown by its value.
3. Write 0 in any place that has no value in the sum.
4. Insert commas to show the periods.

**Method: Standard form → word form**

1. Divide the number into periods.
2. Write the words for each period, followed by the period name.
3. Separate the periods with commas; the Ones period has no period name.

### Mathematical Relationships

* All four forms represent the same number; only the way of writing changes.
* Expanded form shows the value of each digit directly, so it is the link between standard form and place value.
* Word form and short-word form follow the period structure taught with the place-value chart.

## 4. Key Mathematical Vocabulary

### Standard form

**Meaning:** A number written in digits with commas showing the periods.
**Example:** 778,340,821

### Expanded form

**Meaning:** A number written as the sum of the values of its digits.
**Example:** 50,600,204 = 50,000,000 + 600,000 + 200 + 4

### Word form

**Meaning:** A number written completely in words, with commas between the periods.
**Example:** Four milliard, eight million, eleven thousand, ninety-one.

### Short-word form

**Meaning:** Digits of each period followed by the period name.
**Example:** 778 million, 340 thousand, 821.

### Comma

**Meaning:** The mark used to separate the periods of a number.
**Example:** In 3,600,540,650 the commas separate milliards, millions, thousands and ones.

## 5. Simplified Student Explanation

**Unit:** Unit 1 | **Lesson:** Lesson 3 | **Topic:** Many Forms to Write Numbers

The same number can be written in different ways. Take 778,340,821:

1. **Standard form** — just the digits with commas: 778,340,821. This is the form we use most.
2. **Expanded form** — the number broken into the value of each digit:
   700,000,000 + 70,000,000 + 8,000,000 + 300,000 + 40,000 + 800 + 20 + 1.
   Notice there is no "0" in the sum. The Thousands place has a 0, and 0 adds nothing, so we skip it.
3. **Word form** — all in words: Seven hundred seventy-eight million, three hundred forty thousand, eight hundred twenty-one.
4. **Short-word form** — digits plus period names: 778 million, 340 thousand, 821.

**Going from words to digits:** write each period with three digits, using zeros for empty places.
"Three milliard, six hundred million, five hundred forty thousand, six hundred fifty"
→ 3 | 600 | 540 | 650 → 3,600,540,650

**Going from digits to expanded form:** say the value of each digit and add them.
50,600,204 → 50,000,000 + 600,000 + 200 + 4

**Careful:** If a period is not mentioned at all, it becomes 000. For example, "5 milliard, 5 thousand and 5" = 5 | 000 | 005 | 005 = 5,000,005,005.

## 6. Important Rules and Formulas

### Rule 1 — Four forms

Every whole number can be written in standard form, expanded form, word form and short-word form.

### Rule 2 — Zeros in expanded form

A digit of 0 is not written in expanded form, because nothing is in that place value.

### Rule 3 — Three digits per period

When writing a number from words, each period (except possibly the leftmost) must have exactly three digits; fill empty places with 0.

### Formula 1 — Expanded form

`Number = sum of (value of each non-zero digit)`
Example: 1,300,040,005 = 1,000,000,000 + 300,000,000 + 40,000 + 5

### Important Note

Standard form is the most commonly used form; expanded form is the one that shows the value of each digit.

## 8. Worked Examples

### Example 1 — Expanded form → standard form

**Problem:** Write 9,000,000,000 + 300,000,000 + 20,000,000 + 600,000 + 400 + 30 in standard form.

**Method (textbook method):** Put each digit in the place shown by its value and use 0 for empty places.

**Solution:**
Step 1: 9 milliards, 3 hundred millions, 2 ten millions, 0 millions.
Step 2: 6 hundred thousands, 0 ten thousands, 0 thousands.
Step 3: 0 hundreds? No — 400 gives 4 hundreds, 30 gives 3 tens, 0 ones.
Step 4: Write: 9 | 320 | 600 | 430.

**Final Answer:** 9,320,600,430

### Example 2 — Standard form → word form

**Problem:** Write 4,008,011,091 in word form.

**Method:** Divide into periods and name each period.

**Solution:**
Step 1: Periods: 4 | 008 | 011 | 091.
Step 2: 4 → four milliard; 008 → eight million; 011 → eleven thousand; 091 → ninety-one.

**Final Answer:** Four milliard, eight million, eleven thousand, ninety-one.

### Example 3 — Standard form → expanded form with zeros

**Problem:** Write 50,600,204 in expanded form.

**Method:** Write the value of each non-zero digit only.

**Solution:**
Step 1: 5 is in the Ten Millions place → 50,000,000.
Step 2: 6 is in the Hundred Thousands place → 600,000.
Step 3: 2 is in the Hundreds place → 200; 4 is in the Ones place → 4.
Step 4: The zeros are not written.

**Final Answer:** 50,000,000 + 600,000 + 200 + 4

## 9. Common Mistakes

### Common Mistake 1

**Mistake:** Writing a 0 in the expanded form, for example 30,456 = 30,000 + 0 + 400 + 50 + 6.

**Correct Method:** 30,456 = 30,000 + 400 + 50 + 6.

**Why:** The source states that zeros are not needed in expanded form because there is nothing in that place value; the 0 in standard form already shows that the place is empty.

### Common Mistake 2

**Mistake:** Forgetting to fill a missing period with zeros when writing from words, for example writing "5 milliard, 5 thousand and 5" as 5,005,005.

**Correct Method:** Each period after the first must have three digits: 5 | 000 | 005 | 005 = 5,000,005,005.

**Why:** Every period contains hundreds, tens and ones, so an unmentioned period is written as 000.

### Common Mistake 3

**Mistake:** Struggling to say large numbers digit by digit.

**Correct Method:** Group the digits into periods before reading aloud, and use commas when writing numbers in word form.

**Why:** The source's notes for parents advise grouping the numbers into periods when reading aloud and using commas when writing numbers in word form.

## 10. Lesson Summary

**Unit:** Unit 1 | **Lesson:** Lesson 3 | **Topic:** Many Forms to Write Numbers

## Key Concepts

* A number can be written in standard form, expanded form, word form and short-word form.
* Standard form uses digits and commas to show periods, and is used most often.
* Expanded form shows the value of each digit.
* Word form writes the number in words with commas between the periods.
* Short-word form combines digits with period names (778 million, 340 thousand, 821).

## Important Rules

* Zeros are not written in expanded form.
* Each period (after the leftmost) must have exactly three digits in standard form.
* An unmentioned period becomes 000.

## Important Formulas

* `Number = sum of the values of its non-zero digits` (expanded form).
* Example: 778,340,821 = 700,000,000 + 70,000,000 + 8,000,000 + 300,000 + 40,000 + 800 + 20 + 1.

## Key Vocabulary

* standard form, expanded form, word form, short-word form, period, comma

## Problem-Solving Methods

* Words → standard form: write each named period with three digits, filling gaps with zeros.
* Standard form → expanded form: write the value of each non-zero digit and add.
* Expanded form → standard form: put each digit in the place shown by its value, using 0 for missing places.
* Standard form → word form: divide into periods and name each period.

## What Students Should Remember

* The four forms are different ways of writing the *same* number.
* Never write 0 as a term in expanded form.
* Always check that each period has three digits.
