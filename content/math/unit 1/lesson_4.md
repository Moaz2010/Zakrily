**Main mathematical topic:** Putting numbers together (composing) and breaking numbers apart (decomposing) in more than one way, using the place-value chart.

* A number can be decomposed in different ways using the place-value chart.

* 2nd way: as a sum of products, each digit multiplied by the value of its place, for example (5 × 1,000,000) + (4 × 100,000) + …

* How to show a zero in a place when a number is decomposed (the place is simply not written).

**Important skills developed:** decomposing a given number in two ways; composing a number from its decomposed form; completing a place-value chart from a decomposition.

## 3. Lesson Content

**Unit:** Unit 1 | **Lesson:** Lesson 4 | **Topic:** Composing and decomposing numbers

### Mathematical Concepts

* **Composing** numbers means **putting together**.
* **Decomposing** numbers means **broken apart**.
* A number can be decomposed in different ways using the place-value chart.

**Source example — the number 5,456,387:**

| MILLIONS | | | THOUSANDS | | | ONES | | |
|---|---|---|---|---|---|---|---|---|
| H | T | O | H | T | O | H | T | O |
| | | 5 | 4 | 5 | 6 | 3 | 8 | 7 |

**1st way — Expanded Form:**

`5,456,387 = 5,000,000 + 400,000 + 50,000 + 6,000 + 300 + 80 + 7`

**2nd way — as (digit × place value) products:**

`5,456,387 = (5 × 1,000,000) + (4 × 100,000) + (5 × 10,000) + (6 × 1,000) + (3 × 100) + (8 × 10) + (7 × 1)`

### Definitions

**Definition — Composing a number**

Composing a number means putting the parts together to write the number as one whole number in standard form. For example, composing (7 × 1,000,000) + (9 × 100,000) + (8 × 1,000) + (2 × 10) + (5 × 1) gives 7,908,025.

**Definition — Decomposing a number**

Decomposing a number means breaking the number apart into the values of its digits, either as a sum (expanded form) or as a sum of products (digit × place value).

### Rules

**Rule — Two ways to decompose**

A number can be decomposed as a sum of place values (expanded form) or as a sum of products of each digit by the value of its place.

**Rule — Zero places in a decomposition**

A place that contains the digit 0 is not written in a decomposition, because 0 × (place value) = 0 and contributes nothing to the number.

**Rule — Composing from a decomposition**

To compose a number, work out each product, then add all the parts; every place not mentioned in the decomposition contains the digit 0.

### Formulas

**Formula — Decomposition as products**

`Number = (d₁ × p₁) + (d₂ × p₂) + (d₃ × p₃) + …`

**Where:**

* d = a digit of the number
* p = the value of the place that digit occupies (1, 10, 100, 1,000, 10,000, 100,000, 1,000,000, 10,000,000, 100,000,000, 1,000,000,000)

**Formula — Decomposition as a sum (expanded form)**

`Number = value of first digit + value of second digit + … `
Example: 5,456,387 = 5,000,000 + 400,000 + 50,000 + 6,000 + 300 + 80 + 7

### Procedures / Methods

**Method: Decomposing a number**

1. Write the number in the place-value chart, one digit per place.
2. For every non-zero digit, write the digit multiplied by the value of its place, or write the value of the digit.
3. Join all the parts with plus signs.
4. Skip the places that contain 0.

**Method: Composing a number**

1. Work out each product in the decomposition (for example 6 × 100,000 = 600,000).
2. Note which place each part belongs to.
3. Write the digits in their places and put 0 in any place that is missing from the decomposition.
4. Insert commas to show the periods.

### Mathematical Relationships

* Expanded form and the (digit × place value) form describe the same decomposition: 5 × 1,000,000 = 5,000,000.
* Composing and decomposing are opposite (inverse) processes: composing puts the parts together, decomposing breaks the number apart.

### Examples

#### Example 4 (source)

**Problem:** Complete the following.
a. Composed: 8,035,402,176 → Decomposed: ______
b. Composed: ______ → Decomposed: (7 × 1,000,000) + (9 × 100,000) + (8 × 1,000) + (2 × 10) + (5 × 1)

**Solution (source solution):**
a. Decomposed: (8 × 1,000,000,000) + (3 × 10,000,000) + (5 × 1,000,000) + (4 × 100,000) + (2 × 1,000) + (1 × 100) + (7 × 10) + (6 × 1)
b. Composed: 7,908,025

**Final Answer:** a. as above b. 7,908,025

## 4. Key Mathematical Vocabulary

### Composing

**Meaning:** Putting the parts of a number together to write it as one number (standard form).
**Example:** (7 × 1,000,000) + (9 × 100,000) + (8 × 1,000) + (2 × 10) + (5 × 1) composes to 7,908,025.

### Decomposing

**Meaning:** Breaking a number apart into the values of its digits.
**Example:** 4,040,400 decomposes to (4 × 1,000,000) + (4 × 10,000) + (4 × 100).

### Expanded form (1st way of decomposing)

**Meaning:** Writing the number as the sum of the values of its digits.
**Example:** 5,456,387 = 5,000,000 + 400,000 + 50,000 + 6,000 + 300 + 80 + 7

### (Digit × place value) form (2nd way of decomposing)

**Meaning:** Writing the number as the sum of each digit multiplied by the value of its place.
**Example:** (5 × 1,000,000) + (4 × 100,000) + (5 × 10,000) + (6 × 1,000) + (3 × 100) + (8 × 10) + (7 × 1)

## 5. Simplified Student Explanation

**Unit:** Unit 1 | **Lesson:** Lesson 4 | **Topic:** Composing and Decomposing

**Composing** = putting together. **Decomposing** = breaking apart.

Take the number 5,456,387. You can break it apart in two ways.

**Way 1 (expanded form):** write what each digit is worth and add:
5,000,000 + 400,000 + 50,000 + 6,000 + 300 + 80 + 7

**Way 2 (digit × place value):** write each digit times the value of its place:
(5 × 1,000,000) + (4 × 100,000) + (5 × 10,000) + (6 × 1,000) + (3 × 100) + (8 × 10) + (7 × 1)

Both ways give the same number.

**Going backwards (composing):** if you are given
(7 × 1,000,000) + (9 × 100,000) + (8 × 1,000) + (2 × 10) + (5 × 1)
then work out each part: 7,000,000 + 900,000 + 8,000 + 20 + 5 = 7,908,025.

**Careful with zeros:** places that are missing in the decomposition become 0 in the number. In 7,908,025 there is no "ten thousands" part in the decomposition, so a 0 goes in the Ten Thousands place.

## 6. Important Rules and Formulas

### Rule 1 — Meaning

Composing = put together; decomposing = break apart.

### Rule 2 — Two ways of decomposing

Either as a sum of values (expanded form), or as a sum of (digit × place value) products.

### Rule 3 — Zeros

A place holding 0 is not written in a decomposition; when composing, any missing place is filled with 0.

### Formula 1 — Decomposition

`Number = (digit × place value) + (digit × place value) + …`

### Important Note

Composing and decomposing are opposite operations, so each one can be used to check the other.

## 9. Common Mistakes

### Common Mistake 1

**Mistake:** Mixing up the words compose and decompose.

**Correct Method:** Composing = putting together (writing the standard number); decomposing = breaking apart (writing the parts).

**Why:** The source's note for parents says to make sure the child knows the difference between the terms compose and decompose.

### Common Mistake 2

**Mistake:** Forgetting the 0 places when composing, for example writing (7 × 1,000,000) + (9 × 100,000) + (8 × 1,000) + (2 × 10) + (5 × 1) as 798,025.

**Correct Method:** Fill each missing place with 0 → 7,908,025.

**Why:** The source's note for parents says to make sure the child knows how to represent a zero in a place when the number is decomposed.

## 10. Lesson Summary

**Unit:** Unit 1 | **Lesson:** Lesson 4 | **Topic:** Composing and Decomposing

## Key Concepts

* Composing means putting a number together; decomposing means breaking it apart.
* A number can be decomposed in different ways using the place-value chart.
* 1st way: expanded form (sum of values). 2nd way: sum of (digit × place value) products.
* Places containing 0 are left out of the decomposition and filled back in when composing.

## Important Rules

* Decomposition: write each non-zero digit times the value of its place.
* Composition: work out the products, add them, and write 0 in every missing place.
* Composing and decomposing are inverse processes.

## Important Formulas

* `Number = (d₁ × p₁) + (d₂ × p₂) + …` where d = digit and p = value of its place.
* Example: 5,456,387 = (5 × 1,000,000) + (4 × 100,000) + (5 × 10,000) + (6 × 1,000) + (3 × 100) + (8 × 10) + (7 × 1).

## Key Vocabulary

* composing, decomposing, expanded form, place value, place-value chart

## Problem-Solving Methods

* Using the place-value chart to line up digits before decomposing.
* Working out products and adding to compose.
* Converting units first (16 ten thousands = 160,000) before composing.

## What Students Should Remember

* Decompose = break apart; compose = put together.
* Missing places in a decomposition are zeros in the number.
