## 3. Lesson Content

**Unit:** Unit 1 | **Lesson:** Lesson 5 | **Topic:** Comparing big numbers

### Mathematical Concepts

#### First case — The numbers have different numbers of digits

When comparing numbers, the number which has more digits is the greater.

**Source example:** 5,302,200 > 899,529, because 5,302,200 has more digits than 899,529.

#### Second case — The numbers have the same number of digits

You can compare two numbers with the same number of digits **by starting at the left and moving right** until you come to a pair of digits that **do not have the same value**.

**Source example:** Compare 12,673 and 12,763. Start at the left and check each place until the digits are different.

| Step 1 | Step 2 | Step 3 |
|---|---|---|
| Compare the Ten Thousands: 12,673 and 12,763 → same digit of Ten Thousands (1) | Compare the Thousands: same digit of Thousands (2) | Compare the Hundreds: 6 and 7 → 7 > 6 |

Then **12,763 > 12,673**.

#### More examples from the source

* 754,042 < 755,950
* 42,437 > 42,347
* 755,972 < 1,752,421
* 6,406,367 = 6,406,367

#### Forming the greatest and the smallest number

* To create the **greatest** number, arrange the digits from greatest to least.
* To create the **smallest** number, arrange the digits from least to greatest.
* **Note from the source:** if the digits contain "zero", you cannot put it on the left of the number.

### Definitions

**Definition — Greater than (>)**

The symbol > means "is greater than"; it is written between two numbers with the greater number on the left, for example 5,302,200 > 899,529.

**Definition — Less than (<)**

The symbol < means "is less than", for example 754,042 < 755,950.

**Definition — Equal to (=)**

The symbol = means the two numbers have exactly the same value, for example 6,406,367 = 6,406,367.

### Rules

**Rule — Comparing numbers with different numbers of digits**

The number which has more digits is the greater number.

**Rule — Comparing numbers with the same number of digits**

Start at the left and move right until you reach a pair of digits that do not have the same value; the number with the greater digit in that place is the greater number.

**Rule — Forming the greatest number**

Arrange the digits from greatest to least.

**Rule — Forming the smallest number**

Arrange the digits from least to greatest, but a zero may not be placed at the left of the number; put the next smallest digit first and the zero second.

### Procedures / Methods

**Method: Comparing two whole numbers**

1. Count the digits of each number. If the counts are different, the number with more digits is greater.
2. If the counts are the same, line up the numbers and start comparing from the leftmost place.
3. Move right, place by place, while the digits are equal.
4. At the first place where the digits differ, the number with the greater digit is the greater number.
5. Write the correct symbol: >, < or =.

**Method: Finding a missing digit in a comparison**

1. Compare the places where both numbers already have digits.
2. Find the place of the missing digit and decide what values would make the sentence true.
3. Choose a digit that satisfies the comparison, then check by re-reading the sentence.

**Method: Forming the greatest / smallest number from given digits**

1. Count the digits given; the answer must use all of them.
2. For the greatest number: order them from greatest to least.
3. For the smallest number: order them from least to greatest; if 0 is one of the digits, place the smallest non-zero digit first, then the 0.

### Mathematical Relationships

* More digits always means a greater whole number.
* The leftmost place has the greatest place value, so it decides the comparison first.
* Forming the greatest number puts the largest digits in the places with the greatest place value.

### Examples

#### Example 1 (source)

**Problem:** Write (>, < or =) to compare.
a. 37,048 ___ 37,184 b. 217,906 ___ 271,906
c. 4,010,065 ___ 4,000,056 d. 810,340 ___ 810,340

**Solution:** Compare from the left until the digits differ (the source circles that place).
a. The Hundreds place: 0 < 1 → <
b. The Ten Thousands place: 1 < 7 → <
c. The Ten Thousands place: 1 > 0 → >
d. All digits are the same → =

**Final Answer:** a. < b. < c. > d. =

#### Example 2 (source)

**Problem:** Complete.
a. The smallest number formed from 3, 7, 1, 9, 2, 6, 5 is ______
b. The smallest number formed from 8, 5, 0, 1, 3, 9 is ______
c. The greatest number formed from 4, 2, 1, 3, 7, 6, 5 is ______
d. The greatest number formed from 5, 0, 6, 2, 1, 7, 4 is ______

**Solution:** Use the two rules (greatest → order digits from greatest to least; smallest → order from least to greatest, with no zero on the left).

**Final Answer:** a. 1,235,679 b. 103,589 c. 7,654,321 d. 7,654,210

## 4. Key Mathematical Vocabulary

### Greater than (>)

**Meaning:** Shows that the number on the left is bigger than the number on the right.
**Example:** 42,437 > 42,347

### Less than (<)

**Meaning:** Shows that the number on the left is smaller than the number on the right.
**Example:** 754,042 < 755,950

### Equal (=)

**Meaning:** Shows that the two numbers have the same value.
**Example:** 6,406,367 = 6,406,367

### Number of digits

**Meaning:** How many digits a number is written with; among whole numbers, more digits means a greater number.
**Example:** 5,302,200 (7 digits) > 899,529 (6 digits)

### Greatest number / smallest number

**Meaning:** The largest or the smallest number that can be formed using a given set of digits, each used once.
**Example:** From 8, 5, 0, 1, 3, 9 the smallest number is 103,589.

## 5. Simplified Student Explanation

**Unit:** Unit 1 | **Lesson:** Lesson 5 | **Topic:** Comparing Big Numbers

To compare two numbers, first **count the digits**.

* More digits = bigger number.
  5,302,200 has 7 digits, 899,529 has 6 digits, so 5,302,200 > 899,529.

If both numbers have the **same number of digits**, start at the **left** and compare place by place until you find digits that are different.

Compare 12,673 and 12,763:
* Ten thousands: 1 and 1 → same, keep going.
* Thousands: 2 and 2 → same, keep going.
* Hundreds: 6 and 7 → different! 7 is bigger.
So 12,763 > 12,673.

The symbols:
* `>` means "greater than"
* `<` means "less than"
* `=` means "equal to"

**Making the biggest and smallest numbers:**
* Biggest: put the digits in order from biggest to smallest.
  From 4, 2, 1, 3, 7, 6, 5 → 7,654,321
* Smallest: put them from smallest to biggest.
  From 3, 7, 1, 9, 2, 6, 5 → 1,235,679
* **If there is a 0**, it cannot go first. From 8, 5, 0, 1, 3, 9 the smallest is 103,589 (the 1 goes first, then the 0).

## 6. Important Rules and Formulas

### Rule 1 — Different numbers of digits

The number with more digits is greater.

### Rule 2 — Same number of digits

Compare from the left, moving right, until the digits differ; the greater digit makes the greater number.

### Rule 3 — Greatest number

Arrange the given digits from greatest to least.

### Rule 4 — Smallest number

Arrange the given digits from least to greatest; a zero cannot be placed at the left.

### Important Note

If all digits in both numbers are the same, the numbers are equal and the symbol is =.

### Question 6 (Challenge)

**Skill:** Analysis

**Type:** Find and correct the error

**Question:** Describe the error in the following number sentence, and then explain how you would correct it: 24,152,614 < 24,125,614

**ANSWER:** The sentence is wrong. The correct sentence is 24,152,614 > 24,125,614.

**MODEL ANSWER:**
Step 1: Both numbers have 8 digits, so compare from the left.
Step 2: 24,1… is the same in both numbers (Ten Millions, Millions and Hundred Thousands places).
Step 3: The next place (Ten Thousands) gives 5 in the first number and 2 in the second number, and 5 > 2.
Step 4: So the first number is the greater one, and the symbol < must be changed to >.

**Final Answer:** The error is using < instead of >; the correct sentence is 24,152,614 > 24,125,614.

## 9. Common Mistakes

### Common Mistake 1

**Mistake:** Comparing from the right (the Ones place) instead of the left.

**Correct Method:** Start at the left and move right until you come to a pair of digits that do not have the same value.

**Why:** The leftmost place has the greatest place value, so it decides which number is greater; the source's method starts at the left.

### Common Mistake 2

**Mistake:** Putting the zero on the left when forming the smallest number, for example writing 035,589.

**Correct Method:** Put the smallest non-zero digit first, then the zero (103,589).

**Why:** The source's note says that if the digits contain "zero" you cannot put it on the left of the number.

### Common Mistake 3

**Mistake:** Difficulty deciding which place to compare.

**Correct Method:** First circle the place where the digits are different, then compare only those digits.

**Why:** The source's note for parents suggests letting the child circle the place where the digits are different.

## 10. Lesson Summary

**Unit:** Unit 1 | **Lesson:** Lesson 5 | **Topic:** Comparing Big Numbers

## Key Concepts

* The number with more digits is the greater number.
* Numbers with the same number of digits are compared from the left, place by place, until the digits differ.
* The symbols used are > (greater than), < (less than) and = (equal).
* The greatest number from a set of digits orders them from greatest to least; the smallest orders them from least to greatest.

## Important Rules

* More digits → greater number.
* Same number of digits → compare from the left.
* All digits identical → the numbers are equal.
* A zero cannot be placed at the left of a number.

## Important Formulas

* Comparison is decided at the first place (from the left) where the digits differ.
* Greatest number = digits in descending order; smallest number = digits in ascending order (zero not first).

## Key Vocabulary

* greater than (>), less than (<), equal (=), number of digits, greatest number, smallest number

## Problem-Solving Methods

* Counting digits, then comparing place by place from the left.
* Testing digits to satisfy a comparison sentence with a missing digit.
* Working out each described number first (for example 1,000 less than 13,495) before comparing.

## What Students Should Remember

* Always start comparing from the left.
* Count the digits first — it can settle the comparison at once.
* Zero is never the first digit of a number.
